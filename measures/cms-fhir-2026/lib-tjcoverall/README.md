# TJCOverall

## Intent

Shared CQL library TJCOverall version '8.24.000', published once so that
measures depend on it instead of each carrying a copy. Included by these measure
packages in this collection, directly or through another library:

- `cms/anticoagulation-therapy-for-atrial-fibrillation-flutter`
- `cms/antithrombotic-therapy-by-end-of-hospital-day-2`
- `cms/discharged-on-antithrombotic-therapy`
- `cms/intensive-care-unit-venous-thromboembolism-prophylaxis`
- `cms/venous-thromboembolism-prophylaxis`

## Known Limitations

None recorded yet. If you have found something a future implementer of a measure
that uses this library should know, file it in [`knowledge/`](../../../knowledge/).
