# AHAOverall

## Intent

Shared CQL library AHAOverall version '3.0.000', published once so that
measures depend on it instead of each carrying a copy. Included by these measure
packages in this collection, directly or through another library:

- `cms/coronary-artery-disease-cad-beta-blocker-therapy-prior-myocardial-infarction-mi-or-left-ventricular-systolic-dysfunction-lvef-less-than-or-equal-to-40`
- `cms/heart-failure-hf-angiotensin-converting-enzyme-ace-inhibitor-or-angiotensin-receptor-blocker-arb-or-angiotensin-receptor-neprilysin-inhibitor-arni-therapy-for-left-ventricular-systolic-dysfunction-lvsd`
- `cms/heart-failure-hf-beta-blocker-therapy-for-left-ventricular-systolic-dysfunction-lvsd`

## Known Limitations

None recorded yet. If you have found something a future implementer of a measure
that uses this library should know, file it in [`knowledge/`](../../../knowledge/).
