# PalliativeCare

## Intent

Shared CQL library PalliativeCare version '1.18.000', published once so that
measures depend on it instead of each carrying a copy. Included by these measure
packages in this collection, directly or through another library:

- `cms/breast-cancer-screening`
- `cms/cervical-cancer-screening`
- `cms/colorectal-cancer-screening`
- `cms/controlling-high-blood-pressure`
- `cms/diabetes-glycemic-status-assessment-greater-than-9`
- `cms/preventive-care-and-screening-body-mass-index-bmi-screening-and-follow-up-plan`

## Known Limitations

None recorded yet. If you have found something a future implementer of a measure
that uses this library should know, file it in [`knowledge/`](../../../knowledge/).
