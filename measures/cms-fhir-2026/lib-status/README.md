# Status

## Intent

Shared CQL library Status version '1.15.000', published once so that
measures depend on it instead of each carrying a copy. Included by these measure
packages in this collection, directly or through another library:

- `cms/antidepressant-medication-management`
- `cms/appropriate-testing-for-pharyngitis`
- `cms/appropriate-treatment-for-st-segment-elevation-myocardial-infarction-stemi-patients-in-the-emergency-department`
- `cms/breast-cancer-screening`
- `cms/cervical-cancer-screening`
- `cms/childhood-immunization-status`
- `cms/children-who-have-dental-decay-or-cavities`
- `cms/closing-the-referral-loop-receipt-of-specialist-report`
- `cms/colorectal-cancer-screening`
- `cms/controlling-high-blood-pressure`
- `cms/diabetes-glycemic-status-assessment-greater-than-9`
- `cms/functional-status-assessment-for-total-hip-replacement`
- `cms/preventive-care-and-screening-body-mass-index-bmi-screening-and-follow-up-plan`
- `cms/primary-caries-prevention-intervention-as-offered-by-dentists`
- `cms/weight-assessment-and-counseling-for-nutrition-and-physical-activity-for-children-adolescents`
