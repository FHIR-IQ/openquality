# AlaraCommonFunctions

## Intent

Shared CQL library AlaraCommonFunctions version '1.10.000', published once so that
measures depend on it instead of each carrying a copy. Included by these measure
packages in this collection, directly or through another library:

- `cms/excessive-radiation-dose-or-inadequate-image-quality-for-diagnostic-computed-tomography-in-adults-clinician`
- `cms/excessive-radiation-dose-or-inadequate-image-quality-for-diagnostic-computed-tomography-in-adults-facility-iqr`
- `cms/excessive-radiation-dose-or-inadequate-image-quality-for-diagnostic-computed-tomography-in-adults-facility-oqr`

## Known Limitations

None recorded yet. If you have found something a future implementer of a measure
that uses this library should know, file it in [`knowledge/`](../../../knowledge/).
